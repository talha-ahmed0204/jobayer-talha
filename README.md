# Jobayer Ahmed Talha — Portfolio

Personal portfolio of Jobayer Ahmed Talha, a Computer Science diploma student from Dhaka, Bangladesh.

Spider-themed, interactive site built with plain HTML, CSS and JavaScript, plus a Three.js 3D web-globe.

## Features

- Spider theme: interactive web background, click-to-shoot webs, a spider that drops as you scroll
- Three.js 3D web-globe (lazy-loaded) and 3D card tilt
- Mobile menu, scroll progress bar, back-to-top, copy-email button
- Self-hosted fonts, SEO and social preview tags, structured data, custom 404 page
- Accessible: skip link, keyboard focus styles, reduced-motion support
- Lighthouse: 100 on desktop for Performance, Accessibility, Best Practices and SEO

## Run locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080.

## Deploy

Import this repo in [Vercel](https://vercel.com/new) — no build settings needed.
